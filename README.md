# hidayattaufiqur.dev

Personal portfolio and blog. Built with Astro, Vue 3, and UnoCSS.

🔗 https://hidayattaufiqur.dev

## Stack

- [Astro 6](https://astro.build) (static)
- [Vue 3](https://vuejs.org) + TypeScript
- [UnoCSS](https://unocss.dev)
- MDX for blog posts and case studies
- Nix flake dev environment

## Dev

```bash
npm install
npm run dev      # localhost:1977
npm run build
npm run preview
```

Node.js >= 22.12 required.
